# ClipSticky

クリップボードの最新の内容を、画面の隅に付箋のように表示する Windows 用の小さなアプリです。
コピーするたびに表示が更新され、他のアプリのフォーカスは奪いません。

- テキスト・画像・ファイル(コピーしたファイルのパス一覧)に対応
- 最前面・タスクバー非表示・フォーカスを奪わない
- 角丸のモダンなデザイン。テーマ(イエロー / ライト / ダーク)を切り替え可能
- 制御文字・不可視文字の表示、文字コード一覧(Unicode / UTF-8)、文字数・行数・バイト数の表示
- 透明度、背景画像、フォント(書体とサイズ)の指定
- タスクトレイに常駐。依存ランタイムなしの単体 exe(Rust 製)

## 動作環境

- Windows 10 / 11(角丸と枠線の色は Windows 11 のみ。Windows 10 では角が四角になります)

## インストール

[Releases](https://github.com/equinox79/ClipSticky/releases) から `ClipSticky-vX.Y.Z-windows-x64.zip` をダウンロードし、
展開した `clipsticky.exe` を好きな場所に置いて実行してください。インストーラーはありません。
削除するときは exe を消すだけです(設定は `%APPDATA%\ClipSticky` に残ります)。

署名していないため、初回起動時に Windows の SmartScreen が警告を出すことがあります。
その場合は「詳細情報」→「実行」を選んでください。zip と同じ場所にある `.sha256` ファイルで、ダウンロードしたファイルを確認できます。
## ビルドと実行

[Rust](https://www.rust-lang.org/tools/install)(stable)が必要です。

```powershell
cargo run --release
```

`target\release\clipsticky.exe` が単体で動きます。好きな場所にコピーして使えます。

## 使い方

| 操作 | 内容 |
| --- | --- |
| クリップボードにコピー | 内容を表示し、ウィンドウを前面に出す(フォーカスは奪わない) |
| ウィンドウをドラッグ | 移動 |
| 右下・右端・下端をドラッグ | リサイズ |
| マウスホイール | 長いテキストのスクロール |
| 右上の × | ウィンドウを隠す(アプリは終了しない) |
| 画像ファイルをウィンドウにドロップ | 背景画像に設定 |
| トレイアイコンを左クリック | ウィンドウを表示 |
| ウィンドウまたはトレイアイコンを右クリック | メニューを開く |

### トレイメニュー

- **表示**: 隠れているウィンドウを出す
- **監視を一時停止 / 再開**: クリップボードの更新に反応するかどうか
- **テキスト表示**: 通常 / 制御文字を表示 / 文字コード一覧(下記)
- **テーマ**: イエロー / ライト / ダーク
- **透明度**: 100% 〜 50%(標準は 96%)
- **背景画像**: 画像を選択 / 解除
- **フォント**: フォント選択ダイアログで書体とサイズを選ぶ / 既定に戻す(標準は Yu Gothic UI・15px)
- **終了**: アプリを終了する

### テキストの表示形式

下部には、文字数・行数・UTF-8 でのバイト数を表示します(例: `28 文字 · 3 行 · UTF-8 58B`)。

- **通常**: そのまま表示します(タブは展開します)。
- **制御文字を表示**: 改行やタブなどを `⟦CR⟧⟦LF⟧`、`⟦TAB⟧` のように表示します。
  半角スペースは `·`、全角スペースは `□` で表し、ゼロ幅スペース(`⟦ZWSP⟧`)、BOM、NBSP なども見えるようにします。
  改行・タブは記号の後ろで実際にも改行/タブします。
- **文字コード一覧**: 1 文字 1 行で、文字 / Unicode コードポイント / UTF-8 のバイト列 / 名前(制御文字など)を並べます。
  先頭の 1,000 文字までです。

どの形式でも、表示は先頭の 20,000 文字(文字コード一覧は 1,000 文字)までで、超えた分は省略します。

### フォント

「フォント」→「フォントを選択…」で、書体とサイズを選べます。本文に選んだサイズが使われ、アプリ名やフッターなどの小さな文字は固定サイズです。
太字・斜体などのスタイルの指定は反映されません。選択した内容は設定ファイルの `font` と `font_size`(96dpi 換算の px)に保存されます。

### 背景画像

PNG / JPEG / BMP / GIF / WebP に対応しています。縦横比を保ったまま全面に敷き(はみ出す部分は中央でトリミング)、
文字が読めるように上からテーマの色を重ねます。重ねる濃さは `src/main.rs` の `SCRIM_ALPHA` で変えられます。
大きな画像は読み込み時に長辺 1280px まで縮小します。

## 設定ファイル

位置・サイズ・透明度・テーマ・背景画像は `%APPDATA%\ClipSticky\settings.txt` に保存されます。
`key=value` の行形式で、手で編集することもできます。

```
left=1500
top=24
width=380
height=220
opacity=96
theme=yellow
view=normal
background=C:\Users\me\Pictures\wallpaper.png
font=Meiryo
font_size=16
```

`theme` は `yellow` / `light` / `dark`、`view` は `normal` / `controls` / `codes` です。`background`、`font`、`font_size` は省略できます。ファイルを消すと初期状態に戻ります。

## 仕組み

- `AddClipboardFormatListener` で `WM_CLIPBOARDUPDATE` を受け取ります。
- 他のプロセスがクリップボードを開いているときは、50ms 間隔で最大 5 回リトライします。
- ウィンドウは `WS_EX_NOACTIVATE`(フォーカスを奪わない)、`WS_EX_TOOLWINDOW`(タスクバーに出さない)、
  `WS_EX_LAYERED`(透明度)を付けた Win32 ウィンドウです。描画は GDI で、`windows` クレートから呼んでいます。
- 角丸と枠線の色は DWM(`DwmSetWindowAttribute`)に任せています。
