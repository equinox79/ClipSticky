ClipSticky
特長 インストール GitHub English

クリップボードを見える化します

コピーした最新の内容を、画面の隅に付箋のように表示する小さな常駐アプリです。フォーカスは奪いません。Windows と macOS に対応。

ダウンロード ソースコード

特長

見える

テキスト・画像・ファイル(パスの一覧)を、コピーした瞬間に表示します。

邪魔しない

最前面に出ても、作業中のアプリからフォーカスを奪いません。タスクバーや Dock にも出ません。

確かめられる

制御文字・不可視文字の表示、文字コード一覧、文字数・行数・バイト数。

直せる

改行コード、全角⇔半角、Unicode 正規化などを変換して、クリップボードに入れ直します。

好みに合わせる

テーマ(イエロー / ライト / ダーク)、透明度、背景画像、フォント、日本語 / English。

常駐

タスクトレイ / メニューバーに常駐。右クリックで同じメニューが開きます。

スクリーンショット

複数行のコマンドをコピーしたとき、末尾に改行(↓)が含まれているかどうかが一目で分かります。ターミナルに貼り付けて、うっかり実行されるのを防げます。

インストール

Releases から、お使いの OS 用の zip をダウンロードします。

Windows

  1. ClipSticky-vX.Y.Z-windows-x64.zip を展開
  2. clipsticky.exe を好きな場所に置いて実行

インストーラーはありません。署名していないため、初回に SmartScreen が出たら「詳細情報」→「実行」を選びます。

macOS

  1. ClipSticky-vX.Y.Z-macos-universal.zip を展開
  2. ClipSticky.app を「アプリケーション」へ
  3. 初回は右クリック → 開く

公証を受けていないため、開けないときは xattr -dr com.apple.quarantine /Applications/ClipSticky.app を実行します。Apple M2 で動作確認済みです。
